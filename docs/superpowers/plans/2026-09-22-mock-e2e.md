# Phase 8 Mock E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the whole Agent v1 chain end to end offline, and close the Phase 7 evidence gap for accessibility and blindspot questions.

**Architecture:** Reuse `run_agent`, the three Agents, the condition functions, and the Mock Tool boundary. Add no new public contract, Agent, Tool method, or API. Scenario data lives in one reusable e2e helper module; assertions check the full state chain, not only the terminal status.

**Tech Stack:** Python 3.12, Pydantic v2, pytest; no new dependency.

**Spec:** `docs/superpowers/specs/2026-09-22-mock-e2e-design.md`

## Global Constraints

- Fully offline: no `BAIDU_MAP_AK`, no `RUN_BAIDU_SMOKE`, no real model, no network.
- Accessibility questions must end with Routing facts; blindspot questions must end with Diagnosis coverage facts. Never present POI counts as walking reach or blindspot coverage.
- Fix Runner behaviour only through the Tool Gateway boundary, failing test first; keep the public `LifeCircleBrief`/`EvidenceBundle` contracts unchanged.
- `0` means confirmed absent; `null` means unknown. Distinguish them in assertions.
